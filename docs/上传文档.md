# 检测数据上传 HTTP 协议

本文档只定义客户端与服务端之间的检测数据上传协议。

## 1. HTTP 请求

| 项目 | 约定 |
| --- | --- |
| 请求方法 | `POST` |
| 请求路径 | 服务端配置的上传 URL，例如 `/get.aspx` |
| Content-Type | `application/x-www-form-urlencoded; charset=utf-8` |
| 表单参数 | `result` |
| 上传粒度 | 每个检测结果一个 HTTP 请求 |

请求体格式：

```text
result=<result对象文本>
```

`result` 对象不是严格 JSON：属性名和字符串值使用单引号，服务端应按本协议解析，不能直接使用只支持标准 JSON 双引号的解析器。

## 2. 请求示例

```text
result={cmd:'3',username:'0109001',password:'0109001',items:[{spdm:'123',spmc:'苹果',jcxm:'有机磷和氨基甲酸酯类农药',xmmc:'13',jcz:'12',jcjg:'合格',jcrq:'2026-10-12 20:00:00',twh:'A1',bjdw:'某农贸市场',ybcd:'本地批发市场',weight:'2.5',cljg:'合格'}]}
```

## 3. `result` 外层字段

| 字段 | 类型 | 必填 | 格式/取值 | 字段含义 |
| --- | --- | --- | --- | --- |
| `cmd` | string | 是 | 固定为 `3` | 上传命令类型 |
| `username` | string | 是 | 由客户端上传设置提供 | 上传账号 |
| `password` | string | 是 | 由客户端上传设置提供 | 上传密码 |
| `items` | array text | 是 | `[{...}]` | 检测明细数组；当前客户端每次只包含一个对象 |

## 4. `items` 明细字段

| 字段 | 类型 | 必填 | 格式/默认值 | 字段含义 |
| --- | --- | --- | --- | --- |
| `spdm` | string | 是 | 样品编码，去除空格 | 样品代码 |
| `spmc` | string | 是 | 非空文本 | 样品名称 |
| `jcxm` | string | 是 | 文本 | 检测项目名称 |
| `xmmc` | string | 是 | 当前固定为 `13` | 项目代码 |
| `jcz` | numeric string | 是 | 非数字值转为 `0` | 检测值 |
| `jcjg` | string | 是 | `合格` 或 `不合格` | 检测判定结果 |
| `jcrq` | string | 是 | `yyyy-MM-dd HH:mm:ss` | 检测时间 |
| `twh` | string | 否 | 可为空 | 通道号或托盘位号 |
| `bjdw` | string | 是 | 无值发送 `''` | 被检单位 |
| `ybcd` | string | 是 | 无值发送 `''` | 商品来源 |
| `weight` | string | 是 | 无值发送 `''` | 样品重量 |
| `cljg` | string | 是 | 与 `jcjg` 相同 | 处理/结论结果 |

## 5. 客户端字段转换规则

| 原始值 | 发送值 |
| --- | --- |
| `阴性` | `合格` |
| `阳性` | `不合格` |
| 其他非 `合格`、`不合格` 的判定值 | `合格` |
| 非数字 `testValue` | `jcz:'0'` |
| 空 `bcheckedOrganization` | `bjdw:''` |
| 空 `sampleSource` | `ybcd:''` |
| 空 `weight` | `weight:''` |

## 6. 编码与解析

- 请求体中文按 GB2312 编码。
- 服务端应先按请求体编码解码，再读取 `result` 表单参数。
- `result` 内的单引号对象文本不是标准 JSON。
- 服务端应正确处理中文和空字符串。

## 7. HTTP 响应

成功响应：

```http
HTTP/1.1 200 OK
Content-Type: application/json; charset=utf-8

{"ret":"上传成功"}
```

响应正文使用 UTF-8 编码，成功信息位于 `ret` 字段。客户端成功判断条件仍是响应正文包含 `上传成功`，不解析 JSON 或依赖其他响应字段、HTTP 状态码。正文不包含该字符串时进入失败回调。错误响应也使用 `ret` 字段返回错误信息。

建议状态码：

| 情况 | 状态码 |
| --- | --- |
| 上传成功 | `200` |
| 缺少 `result` 或格式错误 | `400` |
| 请求路径不存在 | `404` |
| 不支持的 HTTP 方法 | `405` |
